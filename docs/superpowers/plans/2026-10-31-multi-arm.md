# Multi-Arm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Several arms, each reaching its own instruments, relaying plates through handoff spots; planner free across zones; a two-arm library prep demo.

**Architecture:** Config gains arm `reach` and a `handoff` type; `transport_instructions` routes through handoffs (one relay block per move); blocks whose route depends on a binding carry per-binding instruction variants that `Block.bind` selects; CP-SAT models variant sizes/locks; parks skip variant removals.

**Spec:** `docs/superpowers/specs/2026-10-31-multi-arm-design.md`

## Global Constraints

- Single-arm workcells (no `reach`) compile to exactly the same blocks as before (v1 examples unchanged).
- A relay block's instructions, in order: `check_status` on every instrument on the route; storage `retrieve` (if src is storage); src thermocycler `open_door`; arm₁ `move src→handoff`; src `close_door`; dst thermocycler `open_door`; arm₂ `move handoff→dst`; dst `close_door`; storage `store` (if dst is storage). Longer chains add one arm move per hop.
- Variant key: tuple of `(var, candidate)` for the variables in the move's source/destination owner, sorted by var. The unbound block's `instructions` = the all-first-candidates variant.
- Fast tier stays ~90 s; 3-batch runs are demo commands, not tests.

## Review Focus

- A var whose candidates span arms used as a move source *and* destination in one block (e.g. `?lh0.dst → ?tc0`): all candidate pairs get variants. Test: Task 3 `test_variants_two_vars`.
- Re-plan with a started variant block: its bound variant (from kept bindings) is the one locked. Test: Task 4 `test_two_arm_replan_valid`.
- Config with a non-handoff instrument reached by two arms → ConfigError. Test: Task 1.
- An arm moving outside its reach → simulator alarm. Test: Task 1.
- Lab-tech park from a zone-2 instrument goes to zone 2's hotel. Test: Task 4.
